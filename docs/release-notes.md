# Beta 16

- Mac settings and help distinguish System Library, folders and shared backup controls, including permissions, media handling and cache behavior.
- Add Folder moves to the window toolbar. Compact folder cards use View Files, Back Up Existing Files and Automatic Backup. An active manual run replaces its start button with Stop This Backup; shared help is shown once.
- Turning off automatic backup stops new task preparation. Folder actions respect global pause, with an explicit Resume All Backups banner. Previously paused sources stay off after migration.
- Failed files show recorded reasons with Show in Finder and per-file Retry. Legacy errors identify missing historical details. Retries survive restart, preserve completed receipts and do not restart unrelated backups.
- The sorting menu keeps a compact width, and failed-file details no longer create a large blank area.

Mac requires Apple Silicon and macOS 14+. Android requires arm64 and Android 10+.
iOS 17+ is available from source. Receiver delivery and cloud backup remain separate states.
