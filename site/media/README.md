# Product demonstration

English and simplified Chinese versions of the same 42-second portrait demo.
H.264/AAC, 1080 × 1920, 30 fps, fast-start MP4. The page chooses matching
video and poster assets from the existing site language preference.

All imagery uses the project's public sample scenery and icon. Device names,
pairing graphics, counts and progress are fictional; the UI is illustrated,
not a recording of a personal device. The QR graphic cannot pair a device.
Motion is illustrated with sample scenery. No personal photo library or device
information is included. Both versions use the same original electric-piano
soundtrack with no voiceover or sampled songs.

Playback requires a user action; no autoplay or upfront video download.
Changing language switches to that version paused at the beginning.
